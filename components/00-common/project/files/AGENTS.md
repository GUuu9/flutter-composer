# 생성 앱 작업 지침

README 순서로 SDK·선택 플랫폼을 준비합니다. 버전은 .fvmrc·versions.json·pubspec/lock·플랫폼 파일을 우선하며 다른 프로젝트의 전역 기본값을 바꾸지 않습니다. 이 앱은 빈 화면이며 기능이 필요하면 docs/04-features.md의 수동 추가 절차를 따릅니다. 실행/권한/기기 검증 전 완료로 안내하지 않습니다.

lib/core/di.dart가 필요한 객체를 생성·주입하고 공유 수명을 소유합니다. Widget은 UI 수명을 담당합니다. 실제 기능이 필요할 때만 ViewModel·Service·Api·Repository 등을 추가하고 빈 클래스·빈 수명 메서드는 만들지 않습니다. 화면 전용 Model은 scenes 기능 옆, 공유 기능 Model은 services 기능 옆에 둡니다. core/composition과 최상위 models는 만들지 않습니다.

Dart 파일은 snake_case, 타입은 PascalCase, 함수/변수는 lowerCamelCase입니다. 외부 입력·payload를 검증하고 초기화 실패·구독·화면 해제 후 결과 반영을 처리합니다. 모바일 OS의 종료 콜백·비동기 저장 완료를 보장하지 않습니다.

선택하지 않은 플랫폼·패키지를 자동 추가하지 않습니다. 서명키·비밀값·.env·캐시·빌드 결과는 제외하고 앱의 pubspec.lock은 의존성 설치 후 저장합니다. 권한 선언·런타임 요청·거부/철회 동작은 기능별로 함께 기록합니다. 기본 앱에는 기능 소스·검사가 없으며 사용자가 필요한 원본만 복사한 뒤 기능 문서에 따라 패키지·권한·DI를 직접 연결합니다. 공유 객체는 메인 DI에서 한 번 만들고 통신은 필요한 시점에 시작/종료합니다. 기능 설명서가 포함된 것은 기능 설치·연결·권한 승인을 뜻하지 않습니다.

기본 검사는 짧은 구문·diff 검사입니다. 설치·분석/테스트·Gradle/Xcode 빌드·GUI/기기는 명시적으로 요청한 범위에서 수행하고 실제 결과와 미검증을 구분합니다. Composer state를 고쳐 성공으로 위장하지 않습니다. 커밋·push·배포는 요청 범위에서만 수행합니다.

앱 진입 구조는 main.dart → core/app.dart의 MobileApp이며 main에서 core/di.dart의 createAppDependencies() 결과를 전달합니다. AppDependencies는 생성자로 의존성을 받고 createAppDependencies는 실제 객체를 구성·주입합니다. di.dart는 Flutter Widget/MaterialApp을 import하거나 앱 진입 Widget을 만들지 않습니다. app.dart는 전달받은 객체를 화면에 연결하고 실제 해제 대상이 있을 때 최종 정리를 호출합니다. 빈 앱에는 빈 dispose를 만들지 않습니다.

기능 연결 시 기능별 문서의 DI 등록·실제 시작 메서드·사용·해제를 적용하고 versions.json의 features에 적용한 구현/직접 의존성 버전을 기록합니다. pubspec/실제 lock·검증 결과를 함께 보관하며 버전 기록만으로 설치/동작 검증 완료로 표시하지 않습니다.

코드/설정 작성 안내는 언어를 지정한 코드 블록으로 쓰고, 블록 첫 부분에 해당 언어의 주석으로 파일 경로·추가 위치·기존 내용 병합/교체 여부를 표시합니다. 호출 예제는 실제 소비자 파일과 메서드 본문 일부임을 구분하고 가변 파일명은 자리표시자라고 명시합니다. 터미널 명령에는 실행 위치를 표시합니다. JSON은 jsonc 설명 예제로 파일/위치를 주석 안내하되 실제 JSON 저장 시 주석을 제외하도록 명시합니다.

versions.json의 초기 값은 사용자 동작 확인 조합입니다. 앱 README에서 기준과 현재 PC의 실제 선택 버전을 구분하고 정상 동작하면 유지합니다. 오류 발생 시 경로/설치/라이선스/권한 문제부터 구분한 뒤 필요한 도구/SDK/의존성만 변경하는 절차를 제공합니다. 기준 버전·전역 기본값을 자동 갱신하거나 후보 버전을 검증 완료로 표시하지 않습니다. 실제 설정/선택 파일·lock·결과·복귀를 함께 관리하고 사용자 확인과 신규 생성 앱의 검증을 구분합니다.
